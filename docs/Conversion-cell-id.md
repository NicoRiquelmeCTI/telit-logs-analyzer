🔍 Formato del Cell ID LTE

El valor hexadecimal que aparece en el log (02D2E0C) se interpreta como:

```
Cell Identity (E-UTRAN): eNodeB_ID (20 bits) + Cell_ID (8 bits)
```

📘 Aplicando al ejemplo: 02D2E0C
	1.	Hexadecimal completo: 02D2E0C
→ En binario: 0000 0010 1101 0010 1110 0000 1100
	2.	Separación (bit-level):
	•	eNodeB ID: 02D2E = 0x02D2E = 11566 decimal
	•	Cell ID: 0C = 0x0C = 12 decimal

✔️ Entonces:
	•	eNodeB ID = 11566
	•	Cell (sector) ID = 12
